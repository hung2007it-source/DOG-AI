📚 Hướng dẫn train model Teachable Machine

1

Truy cập Teachable Machine

Mở teachablemachine.withgoogle.com → Chọn Image Project → Standard image model

2

Tạo các class giống chó

Mỗi class = 1 giống chó (vd: Poodle, Husky, Golden Retriever…). Thêm ít nhất 20–50 ảnh/class từ webcam hoặc upload ảnh.

3

Train model

Nhấn "Train Model". Đợi quá trình hoàn tất (thường 1–5 phút tuỳ số class & ảnh).

4

Export & lấy URL

Nhấn "Export Model → Upload my model" → Copy URL (dạng https://teachablemachine.withgoogle.com/models/ABC123/)

5

Paste vào app này

Dán URL vào ô "Cấu hình Model AI" ở trên → Nhấn "Tải Model" → Bắt đầu nhận diện!

Mẹo để model chuẩn hơn

  • Dùng ảnh đa dạng (nhiều góc, ánh sáng khác nhau)
  • Thêm class "Không phải chó" để lọc sai
  • Mỗi class ≥ 50 ảnh sẽ cho độ chính xác tốt hơn
